# Configure a provider-independent NestJS module

**Phase 1.** A host application supplies an initialized `AiModel`. The module exposes `forRoot()` and `forRootAsync()` and accepts an injected async factory with the usual Nest module imports.

## Acceptance criteria

- Synchronous and injected asynchronous configuration each initialize the same exported executor. The supplied model object is preserved and its initialization remains the host's responsibility.
- Invalid model shape and invalid execution configuration fail during bootstrap with actionable diagnostics.
- A custom adapter can express messages, tool results, multiple tool calls, optional usage, and an abort signal without importing a provider SDK. The request supplies eligible tools for chat. Attachment models receive an empty tool list. See [the protocol](../../technical/arch/arch-002.md).
