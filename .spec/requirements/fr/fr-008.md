# Extend the core without requiring vendor dependencies

**Phase 4.** Add optional provider SDK adapters, persistent conversation and discovery state, a SQLite bookkeeping adapter, observability integrations, streaming, and semantic tool discovery through narrow interfaces. Keep the executable registry code-owned. Phase 2 bookkeeping and PostgreSQL are specified in FR-009.

## Acceptance criteria

- Core includes the AI SDK provider protocol for `AiSdkModelAdapter`. The host chooses and installs provider clients and storage drivers. Consumer-owned model adapters continue to work through `generate()`.
- Storage adapters can add searchable metadata and retain conversation or action state in the host's isolation boundary. Stored records cannot create executable tools or revive removed registrations.
- Streaming and semantic retrieval preserve the same tool authorization and request budgets. The core works with deterministic retrieval and unstreamed responses when extensions are absent.
