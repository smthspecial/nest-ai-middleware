# Compose frontend-independent response blocks

**Phase 3.** Return a discriminated union for text, lists, tables, charts, entity lists, and data. Use approved schemas and safe tool projections to serve clients independently of their frontend framework.

## Acceptance criteria

- Reject malformed block data, unknown variants, and unbounded collections before returning them. Fall back to safe text when the model cannot provide valid structure.
- Text answers and host-defined renderers work with every supported model adapter. Clients consume plain data without executing generated frontend code.
