# Register decorated tool methods

**Phase 1.** Build an immutable in-memory registry at startup from Nest class providers and their own methods that declare `@AiTool()`. Compile the declared schema for the named input object. The registry holds compiled validation and private execution bindings alongside model-facing definitions.

## Acceptance criteria

- Only a registered class provider can contribute tools. A method enters the registry only when it declares `@AiTool()`.
- Reject duplicate tool names, unsupported method signatures, invalid schemas or metadata, and missing or ambiguous Nest bindings during startup.
- Use service class and method guards for tool access. Require `NEST_AI_ALLOW_WRITES=true` for tools declaring a create or update operation.
- Registry lookup uses the declared tool name. Public tool metadata contains only schema and selection information. See [provider binding](../../technical/adr/adr-001.md).
