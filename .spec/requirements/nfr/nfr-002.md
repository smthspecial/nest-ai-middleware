# Bound execution time and resource use

Enforce time and size limits at the layer that owns the operation. Validate configuration at startup. The run deadline covers model calls, tool discovery, and dispatch. Attachment extraction uses the same deadline before the chat model loop.

| Limit                               | Current behavior                                                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Tool execution deadline             | 10 seconds by default, including invocation-time guards and Nest provider resolution. Configure with `execution.toolTimeoutMs`. |
| AI run deadline                     | 30 seconds                                                                                                                      |
| Chat model calls and tool proposals | Up to 10 chat model calls and 20 proposed tool calls per run                                                                    |
| Answer and intermediate model text  | Up to 32 KiB per message                                                                                                        |
| Attachment notes                    | Up to 8 KiB per attachment-model response                                                                                       |
| Tool execution order                | Sequential                                                                                                                      |

## Acceptance criteria

- Stop dispatch when the request is cancelled, any enforced limit is reached, or the remaining time is insufficient. Check the whole batch against the remaining call budget. Calls that fail during execution still count toward that budget.
- Validate tool JSON structure and nesting before use. The host owns any tool payload limits through its input schemas and services, along with any HTTP body, message, upload, and traffic limits. Resumed conversations replay all saved turns.
- Propagate abort signals and enforce deadlines even when an asynchronous adapter ignores cancellation. A dispatched call may outlive the response deadline or commit a side effect. Abort prevents later dispatch and requires cooperation from already-running code. Synchronous code that blocks the event loop can delay timer delivery.
