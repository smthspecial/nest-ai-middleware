# Keep execution and disclosure under host control

**Phase 1 onward.** Treat external input, model output, and tool result content as data with explicit trust boundaries. Host-supplied identity, tool policy, and protected service logic govern each execution and each disclosure. Apply the controls in [AUTH-001](../../technical/auth/auth-001.md) as each phase introduces a new interface.

## Acceptance criteria

- A denied request, invalid payload, or unregistered operation produces zero business-method calls. Check tenant and subject isolation with simultaneous requests and a resource access denial.
- Output projection, strict serialization, and sanitized error mapping keep configured sensitive fields, credentials, and stack traces out of model requests and public responses. Instructions embedded in tool results cannot override executor policy.
- The library holds no provider credentials or initialized SDK clients beyond the host's `AiModel` object. Unit and integration tests run without external model APIs.
