# Use optional adapters and streaming discovery integrations

As a host developer, I can integrate different model providers and opt into additional ways to discover tools and deliver answers.

The bundled `SdkModel` supports Vercel AI SDK V3 and V4 language models. The host supplies the provider and credentials. Streaming, semantic discovery, and evaluation of opt-in parallel reads remain open. Each extension must preserve authorization, deadlines, and ordered tool results.
