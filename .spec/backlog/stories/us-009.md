# Use optional adapters and streaming discovery integrations

As a host developer, I can choose external SDKs, streaming, or semantic discovery through optional integrations.

## Acceptance criteria

- Core keeps its small adapter interface and deterministic discovery. Provider-specific code and dependencies live in optional packages.
- Streaming and semantic retrieval preserve execution policy, request budgets, and sanitized outputs.
