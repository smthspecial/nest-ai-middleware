# Continue a stored conversation

As a verified conversation owner, I can continue a stored conversation after restarting the app.

- The host enables sessions and bookkeeping together with `database.adapter`. Session reads and writes require the same verified subject and tenant.
- A lease serializes changes to each session. Successful runs save the final answer returned to the caller. Resuming a session loads all saved turns in order.
- SQLite tests verify restart, owner isolation, overlapping runs, and paged transcript reads.
