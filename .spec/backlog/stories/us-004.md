# Complete a bounded multi-tool read workflow

As an authorized caller, I can ask a question that requires several business reads and receive a validated answer.

## Acceptance criteria

- The model only receives authorized tool definitions. Dependent calls execute over validated rounds with matched results.
- Malformed, oversized, cancelled, and timed-out runs fail predictably. Parallel execution is an explicit opt-in for independent reads.
