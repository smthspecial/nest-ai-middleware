# Choose production storage and observability integrations

As an operator, I can choose a storage adapter and export safe telemetry for supported deployments.

The SQLite adapter is covered by integration tests. PostgreSQL and MongoDB adapters are available, with live database qualification still open. Define bounded metrics and traces and verify the supported deployment combinations. [TASK-011](../tasks/task-011.md) · [TASK-016](../tasks/task-016.md) · [TASK-020](../tasks/task-020.md).
