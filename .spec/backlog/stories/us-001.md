# Register my model and selected NestJS services

As a NestJS developer, I can register an initialized model and expose explicitly decorated methods from my services.

## Completed criteria

- The host can use `forRoot()` or inject the model with `forRootAsync()`.
- Existing services retain their Nest ownership. The registry validates `@AiTool()` declarations at bootstrap.
- An offline model exercises the public contract in the core tests and the packed retail application.
