# Recover approved writes with a stable operation key

As an operator, I can reconcile an ambiguous write outcome without duplicating the business mutation.

## Acceptance criteria

- Concurrent approvals and retries use one stable operation key. Only services with a host-backed idempotency contract can participate.
- Audit captures action state changes. Recovery handles timeout, restart, replay, and permission changes without disclosing data.
