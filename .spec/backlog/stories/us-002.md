# Execute an authorized read in my application's request context

As a NestJS developer, I can invoke an authorized tool using the caller's Nest request context so the same dependencies and authorization apply.

The executor resolves the original provider and checks guards, schema, and deadlines. Reads are enabled by default. Create and update operations require an explicit host opt-in. The packed retail app and Nest fixtures verify authorized dispatch and common denial paths.
