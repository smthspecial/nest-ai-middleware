# Record run outcomes and model usage

As an operator, I can opt into bounded bookkeeping and inspect run outcomes, tool results by status, and reported model usage.

## Acceptance criteria

- One run produces correlated, content-free model and tool records. Missing token usage remains unknown.
- Memory respects capacity and expiry. Store failure emits a sanitized signal while the read workflow remains bounded.
