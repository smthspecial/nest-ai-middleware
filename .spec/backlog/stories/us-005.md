# Record run outcomes and model usage

As an operator, I can opt into bookkeeping with `database.adapter` and inspect run status, tool attempts, and reported model usage.

- Run and event records contain operational metadata. Accepted conversation text lives in the saved turns.
- Backend services can query records for the verified session owner. The logger can report a sanitized storage failure while chat continues.
