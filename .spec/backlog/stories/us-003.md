# Protect the AI endpoint with host Nest guards

As a host developer, I can pass authentication and authorization guards and configure the route so that existing access rules apply to `/ai`.

## Acceptance criteria

- Both registration forms accept ordered guards and apply the host's global prefix.
- The identity resolver and request-scoped services see the verified request. Guard denial produces zero model or tool calls.
