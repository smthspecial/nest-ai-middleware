# Protect the AI endpoint with host Nest guards

As a host developer, I can protect my chat route with Nest guards and pass the verified caller and original request context to the middleware.

- The retail route authenticates before granting read access, validates the payload, and forwards cancellation and request context.
- The host controls input and output prompt checks independently. Rejected content receives a generic HTTP 500, and the rejection code stays in backend storage when configured.
