# Render structured read responses

As a frontend developer, I can consume typed text, list, table, chart, entity, and data blocks.

## Acceptance criteria

- Use validated blocks or safe fallbacks with both structured-capable and text-only adapters.
- Bound block counts and contents. Keep the response contract renderer-independent.
