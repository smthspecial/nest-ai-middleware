# ai_action_events

Durable audit record for each action state revision. This PostgreSQL table is created by `003_actions` in the optional write release.

## Columns

| Column | Type | Constraints |
| --- | --- | --- |
| action_id | uuid | Required. Foreign key to `ai_pending_actions.action_id` with cascading deletion. |
| revision | integer | Required positive state revision. Composite primary key with `action_id`. |
| state | varchar(24) | Required. Uses the action state vocabulary. |
| occurred_at | timestamptz | Required. |
| actor_ref | varchar(128) | Optional verified actor or recovery worker reference. |
| reason_code | varchar(64) | Optional stable code. |

Insert the event atomically with the matching action revision. Keep events immutable and visible only to authorized audit and recovery roles. The host retains these records through the action's reconciliation and configured retention window.
