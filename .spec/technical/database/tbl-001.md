# ai_runs

One row per admitted AI interaction in the plugin's SQLite database. The plugin creates the table when SQLite persistence is enabled.

## Columns

| Column      | Type    | Constraints                                                                |
| ----------- | ------- | -------------------------------------------------------------------------- |
| run_id      | TEXT    | Server-generated UUID and primary key.                                     |
| session_id  | TEXT    | Nullable foreign key to `ai_chat_sessions.id`.                             |
| status      | TEXT    | `running`, `succeeded`, `failed`, `rejected`, `cancelled`, or `timed_out`. |
| started_at  | INTEGER | Start time in Unix milliseconds.                                           |
| finished_at | INTEGER | Completion time in Unix milliseconds for terminal statuses.                |
| error_code  | TEXT    | Optional stable error code.                                                |

The `(session_id, started_at)` index supports inspection by session. Only a `running` row can be finalized. A run may have a null session ID when screening rejects the request before ownership is established.
