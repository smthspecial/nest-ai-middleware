# ai_run_events

One row per generation call or tool attempt in the plugin's SQLite database.

## Columns

| Column        | Type    | Constraints                                                      |
| ------------- | ------- | ---------------------------------------------------------------- |
| run_id        | TEXT    | Foreign key to `ai_runs.run_id` with cascading delete.           |
| sequence      | INTEGER | Event order within the run. Composite primary key with `run_id`. |
| kind          | TEXT    | `model_call` or `tool_attempt`.                                  |
| tool_id       | TEXT    | Stable ID for a known tool attempt.                              |
| tool_name     | TEXT    | Registered name for a known tool attempt.                        |
| invocation_id | TEXT    | Unique plugin-generated UUID for a tool attempt.                 |
| outcome       | TEXT    | `succeeded`, `failed`, `rejected`, `cancelled`, or `timed_out`.  |
| occurred_at   | INTEGER | Event time in Unix milliseconds.                                 |
| duration_ms   | INTEGER | Nonnegative elapsed time.                                        |
| input_tokens  | INTEGER | Nullable model-reported input token count.                       |
| output_tokens | INTEGER | Nullable model-reported output token count.                      |
| error_code    | TEXT    | Optional stable error code.                                      |

Inspect events by `run_id` and order by `sequence`. The plugin writes usage for generation calls and registered tool details for known tool attempts.
