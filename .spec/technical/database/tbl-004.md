# ai_chat_turns

One committed user and assistant exchange in the middleware's SQLite database. The PostgreSQL adapter uses `nest_ai_middleware.chat_turns` and the MongoDB adapter uses `nest_ai_chat_turns`.

## SQLite columns

| Column         | Type    | Constraints                                                          |
| -------------- | ------- | -------------------------------------------------------------------- |
| session_id     | TEXT    | Required. References `ai_chat_sessions.id` with cascading deletion.  |
| position       | INTEGER | Turn position. Forms the primary key with `session_id`.              |
| run_id         | TEXT    | ID of the run that produced the exchange.                            |
| user_text      | TEXT    | The user message, including attachment reference notes when present. |
| assistant_text | TEXT    | The final answer returned to the caller.                             |
| tools          | TEXT    | JSON array of successfully executed tool names.                      |
| tool_ids       | TEXT    | JSON array of their stable tool IDs.                                 |

The `(session_id, run_id)` index supports finding the assistant text for a run. The adapter inserts a turn while holding the session lease. Read turns in pages after verifying ownership. A resumed chat replays all saved turns in order.
