# ai_conversation_turns

One committed user and assistant exchange. This PostgreSQL table is created by optional migration `002_conversations`.

## Columns

| Column | Type | Constraints |
| --- | --- | --- |
| conversation_id | uuid | Required. Foreign key to `ai_conversations.conversation_id` with cascading delete. |
| sequence | integer | Required positive turn number. Composite primary key with `conversation_id`. |
| user_message | text | Required. Bounded, host-projected text. |
| assistant_response | jsonb | Required. Bounded, validated public response. |
| created_at | timestamptz | Required. |

Check the expected conversation revision, insert the next turn, and advance the revision in one transaction. Load through an ownership-checked conversation query. Reuse the existing model message budget to bound the number and size of turns used as context.
