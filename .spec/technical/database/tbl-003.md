# ai_chat_sessions

One row per conversation in the middleware's SQLite database. The PostgreSQL adapter uses `nest_ai_middleware.chat_sessions` and the MongoDB adapter uses `nest_ai_chat_sessions`.

## SQLite columns

| Column      | Type    | Constraints                                      |
| ----------- | ------- | ------------------------------------------------ |
| id          | TEXT    | Primary key. Server-generated session UUID.      |
| subject_id  | TEXT    | Required verified subject ID.                    |
| tenant_id   | TEXT    | Verified tenant ID, when supplied.               |
| turn_count  | INTEGER | Number of saved turns. Defaults to zero.         |
| lease_id    | TEXT    | Run ID holding the current lease, when present.  |
| lease_until | INTEGER | Lease expiry in Unix milliseconds, when present. |

The owner index covers `subject_id` and `tenant_id`. Reads and lease operations check ownership. Saving a turn atomically increments `turn_count` and releases the lease.
