# ai_conversations

One row per stored conversation. This PostgreSQL table is created by optional migration `002_conversations`.

## Columns

| Column | Type | Constraints |
| --- | --- | --- |
| conversation_id | uuid | Primary key. Generated server-side. |
| application_key | varchar(100) | Required installation namespace. |
| tenant_ref | varchar(128) | Required verified tenant or host-defined single-tenant namespace. |
| owner_ref | varchar(128) | Required verified subject reference. |
| revision | integer | Required nonnegative committed turn count. Initially zero. |
| created_at | timestamptz | Required. |
| updated_at | timestamptz | Required. |
| expires_at | timestamptz | Required history retention deadline. |

Index `(application_key, tenant_ref, owner_ref, updated_at)` for owner access and `(application_key, expires_at)` for cleanup. Load and update only under verified ownership and before expiry. The owner reference here is required for enforcement and independent of optional bookkeeping projections.
